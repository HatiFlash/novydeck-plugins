# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting). Include the affected version, the steps to reproduce and the
impact you observed. You will get an answer within 7 days.

## Supported versions

Only the latest release receives security fixes.

## Scope

The plugin catalogue (`registry.json`), the security scan and the first-party plugins published from this repository. A malicious or compromised community plugin can be reported the same way.

# Politique de sécurité (français)

Merci de **ne pas ouvrir d'issue publique** pour un problème de sécurité : utilise
**Security → Report a vulnerability** sur ce dépôt (signalement privé GitHub), avec la version
concernée, les étapes pour reproduire et l'impact constaté. Réponse sous 7 jours. Seule la
dernière version reçoit des correctifs de sécurité.
