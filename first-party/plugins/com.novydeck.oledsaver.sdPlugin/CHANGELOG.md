# Changelog

## 1.1.0
- Cinema mode: monitor "All screens"; OFF also closes overlays opened with the same index even if the screen name/order changed, OFF "all" closes every overlay / Mode cinéma : « Tous les écrans » ; OFF ferme aussi les fenêtres ouvertes avec le même index même si le nom ou l'ordre des écrans a changé.
- New "Keep focus" option: no focus stolen, keyboard does not close, click still does / Nouvelle option « Garder le focus » : pas de vol de focus, le clavier ne ferme pas, le clic ferme.
- Existing settings behave as before / Réglages existants inchangés.

## 1.0.4
- Overlays are tracked by screen name, so another key can close them / Fenêtres suivies par nom d'écran : une autre touche peut les fermer.
- Explicit ON / OFF modes besides Toggle / Modes ON et OFF explicites en plus de Basculer.

## 1.0.2
- Distinct sleeping display logo and matching action icon / Logo écran en veille distinct et icône d’action assortie.
- Redesigned bilingual settings inspector / Inspecteur repensé FR/EN.

## 1.0.1
- Key text is drawn over the background without a black box around letters / Texte des touches sans cadre noir autour des lettres.

## 1.0.0
- Initial per-monitor black fullscreen window and offline property inspector.
