# NovyDeck OLED Saver / Économiseur OLED

EN: Pick a monitor and a mode in the offline inspector. Toggle (the default for saved keys) covers/uncover that monitor. ON covers it idempotently; OFF uncovers it even if another key in the same macro opened it. Two ON keys may cover two different screens. Keyboard input or click closes an overlay; optional close on mouse movement. This is an overlay, not a real display power-off or burn-in prevention guarantee. Does not modify Windows settings.

FR : Sélectionnez un écran et un mode dans l'inspecteur local. Basculer (défaut des touches existantes) masque/démasque l'écran. ON le masque sans doublon ; OFF le découvre même si une autre touche de la macro l'a ouvert. Deux actions ON peuvent masquer deux écrans distincts. Clavier ou clic ferme une fenêtre ; fermeture au mouvement de souris facultative. Ce n'est pas une mise hors tension ni une garantie contre le marquage. Aucun réglage Windows n'est modifié.
