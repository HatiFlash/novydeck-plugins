# NovyDeck OLED Saver / Économiseur OLED

EN: Pick a monitor in the offline inspector. Tap to show a topmost black borderless window on that monitor; tap again, press a keyboard key, or click to close. Optional close on mouse movement. Multiple keys may cover different monitors. This is an overlay, not a real display power-off or burn-in prevention guarantee. Does not modify Windows settings.

FR : Sélectionner un écran dans l'inspecteur local. Appuyer pour ouvrir une fenêtre noire sans bordure au premier plan ; réappuyer, taper une touche clavier ou cliquer pour la fermer. Fermeture au mouvement de souris facultative. Plusieurs touches peuvent couvrir plusieurs écrans. Ce n'est pas une mise hors tension ni une garantie contre le marquage. Aucun réglage Windows n'est modifié.
