# NovyDeck OLED Saver / Économiseur OLED

EN: Pick a monitor and a mode in the offline inspector. Toggle (the default for saved keys) covers/uncover that monitor. ON covers it idempotently; OFF uncovers it even if another key in the same macro opened it. Two ON keys may cover two different screens. Keyboard input or click closes an overlay; optional close on mouse movement. This is an overlay, not a real display power-off or burn-in prevention guarantee. Does not modify Windows settings.

FR : Sélectionnez un écran et un mode dans l'inspecteur local. Basculer (défaut des touches existantes) masque/démasque l'écran. ON le masque sans doublon ; OFF le découvre même si une autre touche de la macro l'a ouvert. Deux actions ON peuvent masquer deux écrans distincts. Clavier ou clic ferme une fenêtre ; fermeture au mouvement de souris facultative. Ce n'est pas une mise hors tension ni une garantie contre le marquage. Aucun réglage Windows n'est modifié.

EN (1.1.0, cinema mode): choose **All screens** or one monitor. In a "switch between two actions" block put OLED Saver ON in state 1 and OFF in state 2. OFF closes the chosen screen(s) even if another key opened them and even if the monitor order changed meanwhile (overlays remember the index they were opened with); OFF on All screens closes every overlay. **Keep focus on the video** stops the overlay from taking focus: keyboard input no longer closes it (a click still does, and so does mouse movement if enabled), so a video player keeps receiving keys. Existing settings keep their behaviour. Not tested against real hardware.

FR (1.1.0, mode cinéma) : choisissez **Tous les écrans** ou un moniteur. Dans un bloc « Basculer entre deux actions », mettez OLED Saver ON dans l'état 1 et OFF dans l'état 2. OFF ferme l'écran choisi même si une autre touche l'a ouvert et même si l'ordre des moniteurs a changé entre-temps (la fenêtre mémorise l'index d'ouverture) ; OFF sur Tous les écrans ferme toutes les fenêtres. **Garder le focus sur la vidéo** empêche la fenêtre de prendre le focus : le clavier ne la ferme plus (le clic la ferme toujours, le mouvement de souris aussi s'il est activé) et le lecteur vidéo continue de recevoir les touches. Les réglages existants gardent leur comportement. Non testé sur du matériel réel.

EN (1.1.0, choosing screens): the inspector now offers **All except the main screen** (recommended for cinema mode: the Windows primary screen where you watch stays visible, everything else goes black), **All screens**, or **Choose** with one checkbox per monitor (at least one required). Chosen screens are matched by name and position, then position, name and index, so OFF still works after a numbering or name change; OFF on "All except the main screen" closes every non-primary overlay. Older single-monitor settings are shown as "Choose" with that screen ticked and are not rewritten unless you change something.

FR (1.1.0, choix des écrans) : l'inspecteur propose **Tous sauf l'écran principal** (recommandé en mode cinéma : l'écran principal Windows où vous regardez reste visible, tout le reste devient noir), **Tous les écrans**, ou **Choisir** avec une case par moniteur (au moins une). Les écrans cochés sont retrouvés par nom et position, puis position, nom et index : OFF fonctionne même si la numérotation ou le nom a changé ; OFF sur « Tous sauf l'écran principal » ferme toutes les fenêtres des écrans non principaux. Les anciens réglages à un seul moniteur s'affichent en « Choisir » avec l'écran coché et ne sont réécrits que si vous changez quelque chose.
