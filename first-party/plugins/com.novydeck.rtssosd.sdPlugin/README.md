# NovyDeck RivaTuner OSD / Overlay RivaTuner

EN: Show or hide the RivaTuner Statistics Server (RTSS) on-screen display from a key or macro. Modes: Toggle (default), ON, OFF. The plugin loads `RTSSHooks64.dll` from your own RTSS installation (found through the registry, then the default Program Files folders) and calls its `GetFlags` / `SetFlags` exports, so no simulated keystroke is needed and it works even though RTSS runs elevated. The key shows OSD ON / OSD OFF from the real state and follows changes made with RTSS hotkeys. If the key flashes an alert: RTSS is not installed (DLL not found) or not running (the change was not reflected). RivaTuner is not included or redistributed. Requires Windows 10+ and RivaTuner Statistics Server running. Validated by hand on one PC; CI uses no RTSS.

FR : Affiche ou masque l'overlay de RivaTuner Statistics Server (RTSS) depuis une touche ou une macro. Modes : Basculer (défaut), ON, OFF. Le plugin charge `RTSSHooks64.dll` de votre propre installation RTSS (registre, puis dossiers Program Files par défaut) et appelle ses exports `GetFlags` / `SetFlags` : aucune touche simulée, et cela fonctionne même si RTSS tourne en mode élevé. La touche affiche OSD ON / OSD OFF d'après l'état réel et suit les changements faits avec les raccourcis RTSS. Alerte : RTSS introuvable (DLL absente) ou non lancé (changement non reflété). RivaTuner n'est ni inclus ni redistribué. Nécessite Windows 10+ et RivaTuner Statistics Server lancé. Validé à la main sur un PC ; la CI n'utilise pas RTSS.
