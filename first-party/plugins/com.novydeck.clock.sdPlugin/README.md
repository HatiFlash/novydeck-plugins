# NovyDeck Clock / Horloge

Native Windows Stream Deck plugin: clock, timer and stopwatch. No Node installation. Set 12-hour mode, date, or timer duration in the local property inspector. Timer and stopwatch: tap to start/pause, hold at least 600 ms to reset. Timer completion flashes and displays an alert. Time is based on the local Windows clock. Timers are not persisted across plugin restarts.

Plugin Windows natif : horloge, minuteur et chronomètre. Aucun Node requis. Réglez le format 12 h, la date et la durée depuis l'inspecteur local. Minuteur et chronomètre : appui bref démarrer/pause ; appui ≥ 600 ms remise à zéro. À l'échéance : alerte et clignotement. Les minuteurs ne survivent pas au redémarrage du plugin.

Install the `.streamDeckPlugin` archive produced by the Windows CI. Source: `first-party/clock` and `first-party/novydeck-sdk`.
