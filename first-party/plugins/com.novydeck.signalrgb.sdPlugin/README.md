# SignalRGB lighting / Éclairage SignalRGB

EN: Add the Lighting action to a key or NovyDeck macro and choose ON or OFF explicitly. The plugin only connects to the installed SignalRGB local API at 127.0.0.1:16038. OFF sends black to the global lighting canvas; it does not physically power down LED hardware. ON re-enables the canvas. There is no per-device selection and no toggle. Connection and HTTP errors trigger an alert. Requires SignalRGB running on the same PC; not tested on actual hardware.

FR : Ajoutez l’action Éclairage à une touche ou macro NovyDeck et choisissez explicitement ON ou OFF. Le plugin ne contacte que l’API locale de SignalRGB sur 127.0.0.1:16038. OFF envoie du noir sur le canvas global, sans couper physiquement les LED. ON réactive le canvas. Pas de sélection par appareil ni de bascule. Toute erreur réseau ou HTTP déclenche une alerte. SignalRGB doit fonctionner sur le même PC ; matériel non testé.
