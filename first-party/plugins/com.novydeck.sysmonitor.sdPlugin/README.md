# NovyDeck System Monitor / Moniteur système

EN: Native CPU load, RAM usage, GPU engine activity (Windows PDH) and NVIDIA GPU temperature (NVML loaded dynamically). Tap any key to open Task Manager. Refresh every 2 seconds. Unavailable measurements show —. CPU temperature shows n/d: Windows does not offer reliable CPU sensor measurements without a third-party driver. GPU temperatures are unavailable for non-NVIDIA hardware. PDH GPU engine counters may be unavailable on some drivers or systems.

FR : Charge CPU, mémoire RAM, moteurs GPU (PDH Windows) et température GPU NVIDIA (NVML à chargement dynamique). Appuyer pour ouvrir le Gestionnaire des tâches. Actualisation toutes les 2 secondes. Données indisponibles : —. Température CPU : n/d, Windows ne fournit pas de mesure fiable sans pilote tiers. Température GPU hors NVIDIA indisponible.
