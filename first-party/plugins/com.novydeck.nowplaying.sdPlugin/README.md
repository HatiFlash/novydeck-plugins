# NovyDeck Now Playing / Média en cours

EN: Playback, next and previous for the current Windows GSMTC session. Shows album artwork on Play/Pause when supplied by the player; otherwise a default rendered key shows the title and artist. With no active player the key displays “No player” and pressing it displays an alert. Apps without GSMTC support are not controllable.

FR : Lecture/pause, piste suivante et précédente pour la session GSMTC Windows active. Affiche la pochette si fournie par le lecteur ; sinon le titre et l'artiste. En l'absence de lecteur actif, affiche « No player » et une alerte à l'appui. Lecteurs non compatibles GSMTC indisponibles.
