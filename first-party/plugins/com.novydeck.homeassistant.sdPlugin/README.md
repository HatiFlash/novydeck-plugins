# Home Assistant / Maison Home Assistant

EN: Requires a working Home Assistant server (not included), its base URL and a long-lived access token from your Home Assistant user profile. This plugin cannot control Google Home devices without Home Assistant. Install the `.streamDeckPlugin` archive, add an action and enter the URL, then save the token in the property inspector. The token is encrypted for the current Windows account with DPAPI in `%APPDATA%\NovyDeck\plugins\com.novydeck.homeassistant\secrets.bin`; it is shared by this plugin's actions, never exported in Stream Deck settings. Back up/re-enter the token when changing Windows users. No telemetry. Requests only go to the configured server; redirects are refused. HTTP is supported for trusted local networks; prefer HTTPS. Self-signed TLS is refused by default; opting in disables certificate validation and is unsafe on untrusted networks.

Actions: Toggle entity uses `homeassistant.toggle`; Call service uses `domain.service` with an entity and optional JSON object (the chosen entity overrides `entity_id` in the JSON); Display state shows the entity state and unit. Toggle and Display state poll only while visible (default 10 seconds; 2–300 seconds). Enter an entity ID manually or fetch and search the entity list. Connection test uses `GET /api/`. Each request times out after 10 seconds. Service actions can change devices: test with a noncritical entity first.

FR : nécessite un serveur Home Assistant opérationnel (non fourni), son URL racine et un jeton d'accès longue durée créé dans le profil utilisateur Home Assistant. Ce plugin ne pilote pas Google Home sans Home Assistant. Installez l'archive `.streamDeckPlugin`, placez une action, indiquez l'URL, puis enregistrez le jeton dans l'inspecteur. Le jeton est chiffré DPAPI pour le compte Windows courant dans `%APPDATA%\NovyDeck\plugins\com.novydeck.homeassistant\secrets.bin` ; il est partagé entre les touches du plugin et jamais enregistré dans les réglages exportables. En cas de changement de compte Windows, ressaisissez le jeton. Pas de télémétrie ; les redirections sont refusées. Préférez HTTPS ; HTTP est réservé au réseau local de confiance. Accepter un certificat auto-signé désactive la vérification TLS : option risquée, désactivée par défaut.

Actions : Basculer une entité (`homeassistant.toggle`), Appeler un service (`domaine.service`, entité et objet JSON optionnel ; l'entité choisie prime), Afficher un état (état et unité). Les actions Basculer et Afficher interrogent le serveur uniquement quand la touche est visible (10 s par défaut, 2 à 300 s). Tester la connexion utilise `GET /api/`. Délai maximal de 10 s par requête. Testez les services sur des appareils sans risque.

No real Home Assistant server or hardware was used in automated tests / Aucun serveur ni appareil réel testé en CI.
