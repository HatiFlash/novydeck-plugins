# Home Assistant / Maison Home Assistant

EN: Requires a working Home Assistant server (not included), its base URL and a long-lived access token from your Home Assistant user profile. This plugin cannot control Google Home devices without Home Assistant. Install the `.streamDeckPlugin` archive, add an action and enter the URL, then save the token in the property inspector. The token is encrypted for the current Windows account with DPAPI in `%APPDATA%\NovyDeck\plugins\com.novydeck.homeassistant\secrets.bin`; it is shared by this plugin's actions, never exported in Stream Deck settings. Back up/re-enter the token when changing Windows users. No telemetry. Requests only go to the configured server; redirects are refused. HTTP is supported for trusted local networks; prefer HTTPS. Self-signed TLS is refused by default; opting in disables certificate validation and is unsafe on untrusted networks.

Actions: Toggle entity uses `homeassistant.toggle`; Call service uses `domain.service` with an entity and optional JSON object (the chosen entity overrides `entity_id` in the JSON); Display state shows the entity state and unit. Toggle and Display state poll only while visible (default 10 seconds; 2–300 seconds). Enter an entity ID manually or fetch and search the entity list. Connection test uses `GET /api/`. Each request times out after 10 seconds. Service actions can change devices: test with a noncritical entity first.

FR : nécessite un serveur Home Assistant opérationnel (non fourni), son URL racine et un jeton d'accès longue durée créé dans le profil utilisateur Home Assistant. Ce plugin ne pilote pas Google Home sans Home Assistant. Installez l'archive `.streamDeckPlugin`, placez une action, indiquez l'URL, puis enregistrez le jeton dans l'inspecteur. Le jeton est chiffré DPAPI pour le compte Windows courant dans `%APPDATA%\NovyDeck\plugins\com.novydeck.homeassistant\secrets.bin` ; il est partagé entre les touches du plugin et jamais enregistré dans les réglages exportables. En cas de changement de compte Windows, ressaisissez le jeton. Pas de télémétrie ; les redirections sont refusées. Préférez HTTPS ; HTTP est réservé au réseau local de confiance. Accepter un certificat auto-signé désactive la vérification TLS : option risquée, désactivée par défaut.

Actions : Basculer une entité (`homeassistant.toggle`), Appeler un service (`domaine.service`, entité et objet JSON optionnel ; l'entité choisie prime), Afficher un état (état et unité). Les actions Basculer et Afficher interrogent le serveur uniquement quand la touche est visible (10 s par défaut, 2 à 300 s). Tester la connexion utilise `GET /api/`. Délai maximal de 10 s par requête. Testez les services sur des appareils sans risque.

EN (1.1.0, Automatic state): add the **Automatic state** action (NovyDeck **0.19.1 or later** is required for this action and for the Workshop block), pick a sensor from the searchable list (readable name, entity_id and current state; domain filter), then choose an optional attribute, an operator (equals, not equal, >, <), a value, "for N seconds" and whether to also trigger at startup. The key image follows the rule (active / inactive) without pressing it, and the "becomes active" / "becomes inactive" branches run on real changes only. If Home Assistant is disconnected the last image is kept. URL and token are set once for the whole plugin (token never shown again). Example, OLED Saver: rule `binary_sensor.tv_salon` = `on` for 30 s, active branch runs OLED Saver ON (cinema mode), inactive branch runs OLED Saver OFF. Not tested against a real Home Assistant server or real hardware.

FR (1.1.0, État automatique) : ajoutez l'action **État automatique** (NovyDeck **0.19.1 ou plus récent** requis pour cette action et pour le bloc de l'Atelier), choisissez un capteur dans la liste filtrable (nom lisible, entity_id et état actuel ; filtre par domaine), puis un attribut facultatif, un opérateur (égal, différent, >, <), une valeur, « depuis N secondes » et le déclenchement éventuel au démarrage. L'image de la touche suit la règle (active / inactive) sans appui, et les branches « devient actif » / « devient inactif » ne s'exécutent que lors d'un vrai changement. Si Home Assistant est déconnecté, la dernière image est conservée. L'URL et le jeton sont réglés une fois pour tout le plugin (jeton jamais réaffiché). Exemple OLED Saver : règle `binary_sensor.tv_salon` = `on` depuis 30 s, branche active : OLED Saver ON (mode cinéma), branche inactive : OLED Saver OFF. Non testé avec un vrai serveur Home Assistant ni du matériel réel.

No real Home Assistant server or hardware was used in automated tests / Aucun serveur ni appareil réel testé en CI.

EN (1.1.1, token security): the token is encrypted under your Windows account and **bound to the address** it was entered for; it is never sent to a different address. If you change the address, enter the token again (otherwise the saved one is erased). "Test connection" uses the saved token only for the saved address; for another address, type the token first (it is not saved). Addresses found in older (1.0.x) key settings are only suggested, never applied automatically. An http:// or ws:// address that is not local shows a clear-text warning (the token and commands travel unencrypted): use https. "Do not verify the certificate" is under **Advanced**, only accepted for local addresses, and will be removed in favour of certificate pinning.

FR (1.1.1, sécurité du jeton) : le jeton est chiffré sous votre compte Windows et **lié à l'adresse** pour laquelle il a été saisi ; il n'est jamais envoyé à une autre adresse. Si vous changez l'adresse, ressaisissez le jeton (sinon celui enregistré est effacé). « Tester la connexion » n'utilise le jeton enregistré que pour l'adresse enregistrée ; pour une autre adresse, saisissez d'abord le jeton (il n'est pas enregistré). Les adresses trouvées dans d'anciens réglages de touche (1.0.x) sont seulement suggérées, jamais appliquées automatiquement. Une adresse http:// ou ws:// non locale affiche un avertissement de transmission en clair (jeton et commandes non chiffrés) : utilisez https. « Ne pas vérifier le certificat » est sous **Avancé**, accepté uniquement pour une adresse locale, et sera retiré au profit de l'épinglage du certificat.
