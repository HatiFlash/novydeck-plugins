# Wallpaper Engine 1.0.6 — next / pause / stop-play

Official command reference: https://help.wallpaperengine.io/en/functionality/cli.html

The official “Next Wallpaper” syntax is `-control nextWallpaper [-location <string>] [-monitor <number>]`; “Skips to the next wallpaper of a given monitor or all monitors if none specified.” The documented monitor index begins at 0 (in the Open Playlist and Open Wallpaper parameters). Screen 1 in the inspector maps to `-monitor 0`. Version 1.0.3 already constructed this syntax. No incorrect command was reproduced; the actual cause of a button apparently doing nothing is unknown. Check the running Wallpaper Engine instance, active playlist on the selected display, display index or internal location from that PC's `config.json`, and whether the same command changes the wallpaper directly on that PC. An exit code of zero does not establish that a visible wallpaper changed. The CLI page does not state a strict playlist prerequisite for `nextWallpaper` or provide a query for pause state; an active playlist is a troubleshooting check, not a proven prerequisite.

The same official page documents `-control pause` as pausing all wallpapers, `-control stop` as stopping them, and `-control play` as resuming them, all without a screen selector. It does not document a stop/play toggle command. Stop / Play sends `stop` on the first press (initial state unknown), then `play` after a successful stop; successful explicit Stop/Play and Pause actions also update the shared local state across visible keys. Pause is distinct from Stop: a paused key resumes with Play, while a Stop / Play key stops unless the last successful command was Stop. A nonzero exit does not change the state. The title shows the next command; appearance updates are marked LOCAL when known. After Stop the Pause/Play appearance is unknown rather than claiming a paused wallpaper. This state is not synchronized with changes made directly in Wallpaper Engine or other clients, and resets when the plugin restarts. The existing explicit Play, Stop, Pause and Profile actions remain available.

Tests use a compiled fake `wallpaper64.exe` on Windows to record real process arguments, including a spaced executable directory, a spaced screen location and playlist name, monitor index 0, and a nonzero exit. They cannot verify Wallpaper Engine itself or a visible wallpaper transition. No Windows wallpaper settings or personal media are changed.
